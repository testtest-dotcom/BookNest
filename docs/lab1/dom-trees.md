# Деревья документа (для переноса в схемы)

- index: html → body → header(nav) + main(h1, section(aside(form), section(article×6, section списка))) + footer
- book: html → body → header(nav) + main(nav, article(h1, figure, section(dl), section, section(article, form)), aside) + footer
- loan: html → body → header(nav) + main(h1, form(fieldset×2)) + footer

Сопоставьте с выданными преподавателем макетами; они не приложены к PDF.
