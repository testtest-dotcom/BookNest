# GitHub: как отправить ЛР 1–4

**Важно:** в архиве находятся готовые ветки и история Git. На GitHub они ещё не опубликованы.

1. Распакуйте архив, откройте терминал в папке `BookNest` и проверьте `git log --oneline` и `git branch`.
2. Создайте пустой репозиторий GitHub (не создавайте на GitHub README/лицензию/.gitignore).
3. Привяжите удалённый репозиторий: `git remote add origin https://github.com/ВАШ_ЛОГИН/booknest.git`.
4. Опубликуйте историю и ветки: `git push -u origin main` и `git push origin course-start lab-1/markup lab-2/styles lab-3/js-app lab-4/api`.
5. Создавайте четыре PR **в таком порядке** (это корректный способ сравнивать последовательные этапы):

| ЛР | base | compare |
| --- | --- | --- |
| 1 | course-start | lab-1/markup |
| 2 | lab-1/markup | lab-2/styles |
| 3 | lab-2/styles | lab-3/js-app |
| 4 | lab-3/js-app | lab-4/api |

6. Прикрепите ссылки на свои четыре PR в СРО. Для каждого PR заполните `docs/PR_TEMPLATE.md`; запишите тесты и приложите реальные скриншоты.

**Если преподаватель выдал GitHub Classroom**, используйте его репозиторий и согласуйте с преподавателем базовую ветку PR. Нельзя считать PR отправленными, пока они не созданы в вашем аккаунте.

В исходном PDF есть требование не менее пяти осмысленных коммитов для ЛР 1; в этой истории начальный этап включает пять коммитов, а каждый следующий этап — отдельные несколько коммитов.
