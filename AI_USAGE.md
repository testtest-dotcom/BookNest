# Использование ИИ

При подготовке исходного учебного шаблона BookNest использовался ИИ-ассистент ChatGPT (GPT-6) для генерации HTML, CSS, JavaScript, структуры Git и пояснений по требованиям лабораторных работ 1–4. Студент обязан проверить весь код, выполнить измерения и скриншоты самостоятельно, исправить выявленные проблемы и быть готовым объяснить каждую строку на защите. Не указывайте непроведённые проверки как выполненные.
